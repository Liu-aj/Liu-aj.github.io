## 💻 编辑器

### Cursor
AI 增强的代码编辑器，基于 VS Code

- **官网**: https://cursor.sh/
- **特点**: 内置 AI 辅助代码编写
- **教程**: [Cursor 完全指南](工具软件/2026-03-18-Tools-Cursor/)

### VS Code
微软出品的轻量级代码编辑器

- **官网**: https://code.visualstudio.com/
- **插件**: 支持丰富的插件生态

### Claude Code
Anthropic 推出的 CLI 编程工具

- **官网**: https://docs.anthropic.com/
- **特点**: 强大的 AI 编程能力
- **教程**: [Claude Code 安装指南](其他/2026-03-19-claude-code-installation-guide/)

## 🔧 命令行工具

### Warp
现代化终端，支持 AI 辅助

- **官网**: https://www.warp.dev/
- **特点**: GPU 加速渲染，内置 AI

### eza
现代化的 `ls` 替代品

- **特点**: 彩色输出，Git 集成
- **教程**: [CLI 工具指南](工具软件/2026-03-18-Tools-CLI-Tools/)

### fd
更友好的 `find` 替代品

- **特点**: 更快的搜索速度，彩色输出

### ripgrep (rg)
超快的 grep 替代品

- **特点**: 基于 Rust，速度极快

## 📦 开发环境

### Docker
容器化平台

- **官网**: https://www.docker.com/
- **用途**: 环境隔离，容器化部署

### Ollama
本地 LLM 运行框架

- **官网**: https://ollama.ai/
- **用途**: 本地运行 Llama/GPT 等模型
