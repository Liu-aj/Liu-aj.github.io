## 角色

| 角色 | 职责 |
|------|------|
| Product Owner | 负责产品 backlog |
| Scrum Master | 确保流程执行 |
| 开发团队 | 交付价值 |

## 事件

| 事件 | 长度 | 目的 |
|------|------|------|
| Sprint | 1-4周 | 开发周期 |
| Planning | 4-8h | 制定计划 |
| Daily | 15min | 同步进度 |
| Review | 1-2h | 演示成果 |
| Retro | 1-2h | 改进反思 |
