# 隐私保护 🔒

> 保护个人隐私

---

## 浏览器隐私

### 隐私浏览
- 使用无痕/隐私模式
- 定期清理 Cookie
- 禁用第三方 Cookie

### 搜索引擎
- 使用 DuckDuckGo
- 使用 Startpage
- 使用 Brave Search

## 密码管理

### 密码原则
- 长度 > 复杂度
- 每个账户不同密码
- 使用密码管理器

### 推荐工具
- Bitwarden (开源)
- 1Password
- KeePass

## 两步验证

### 2FA 方法
| 方法 | 安全性 |
|------|--------|
| SMS | 中 |
| Authenticator App | 高 |
| 硬件密钥 | 最高 |
