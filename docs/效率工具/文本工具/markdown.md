# Markdown 语法 📝

> 轻量级标记语言

***

## 基本语法

### 标题
```markdown
# H1
## H2
### H3
```markdown

### 强调
```markdown
*斜体*
**粗体**
***粗斜体***
~~删除线~~
```

### 列表
```markdown
- 无序列表
- 项目2

1. 有序列表
2. 项目2
```markdown

### 链接与图片
```markdown
[链接文字](URL)
![图片alt](图片URL)
```

## 代码

### 行内代码
```markdown
`const x = 1`
```javascript

### 代码块
~~~markdown
```javascript
const hello = 'world';
```bash

## 表格

```markdown
| 列1 | 列2 | 列3 |
|------|------|------|
| 内容 | 内容 | 内容 |
```markdown

## 高级

### 任务列表
```markdown
- [x] 已完成
- [ ] 未完成
```

### 引用
```markdown
> 引用内容
```markdown

### 水平线
```markdown
---
```
