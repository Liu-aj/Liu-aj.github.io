## 时间管理

### Pomodoro
```bash
工作 25分钟 → 休息 5分钟 → 循环
每4个番茄钟 → 长休息 15-30分钟
```

### GTD
```bash
收集 → 处理 → 组织 → 回顾 → 执行
```
