# 问题排查 🔧

> 整理常见问题的排查方法

---

## 🖥️ 系统问题

### 网络连接
| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法连接 Wi-Fi | 密码错误/信号弱 | 检查密码/靠近路由器 |
| MQTT 连接失败 | 端口被阻/地址错误 | 检查防火墙/地址配置 |

### Docker
| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| 容器无法启动 | 端口占用/配置错误 | 检查端口/查看日志 |
| 镜像拉取失败 | 网络问题 | 配置镜像加速器 |

## 📱 ESP32

### 烧录失败
1. 检查 USB 线是否支持数据传输
2. 检查驱动是否安装（设备管理器）
3. 按住 BOOT 按钮再点击 EN 进入下载模式

### Wi-Fi 连接失败
1. 检查 SSID 和密码
2. 确保 Wi-Fi 是 2.4GHz
3. 检查 Wi-Fi 密码复杂度要求

## 🏠 Home Assistant

### 设备不响应
1. 检查设备电源
2. 检查 Zigbee/蓝牙连接
3. 重启 Home Assistant

### 集成加载失败
1. 检查配置是否正确
2. 查看日志具体错误
3. 重装集成

## 🤖 AI 开发

### LLM 响应慢
1. 检查 GPU 使用率
2. 降低并发请求
3. 使用量化模型

### API 调用失败
1. 检查 API 余额
2. 验证 API Key
3. 检查网络连接
