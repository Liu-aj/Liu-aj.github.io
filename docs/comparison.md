# 技术对比 ⚖️

> 整理常见技术选型对比

---

## 💾 数据库

### MySQL vs PostgreSQL

| 特性 | MySQL | PostgreSQL |
|------|-------|------------|
| 事务支持 | ✅ ACID | ✅ ACID |
| JSON 支持 | ✅ 基础 | ✅ 高级 |
| 性能 | ⚡ 读性能强 | ⚡ 复杂查询强 |
| 适用场景 | Web 应用 | 企业级/分析 |

### MySQL vs MongoDB

| 特性 | MySQL | MongoDB |
|------|-------|---------|
| 数据模型 | 关系型 | 文档型 |
| 事务 | ✅ 支持 | ✅ 支持 |
| 扩展性 | 垂直扩展 | 水平扩展 |
| 适用场景 | 结构化数据 | 半结构化数据 |

## 🤖 AI 模型

### Ollama vs OpenAI API

| 特性 | Ollama | OpenAI API |
|------|--------|------------|
| 部署方式 | 本地运行 | 云端 API |
| 成本 | 一次性硬件成本 | 按 Token 付费 |
| 隐私 | 数据不离本地 | 数据发送云端 |
| 速度 | 取决于硬件 | 取决于网络 |
| 模型选择 | 开源模型 | GPT 系列 |

### GPT-4 vs Claude

| 特性 | GPT-4 | Claude |
|------|-------|--------|
| 上下文 | 128K | 200K |
| 编程能力 | ⚡ 强 | ⚡ 强 |
| 长文本理解 | ✅ | ✅✅ 更强 |
| 安全对齐 | ✅ | ✅✅ 更强 |

## 🏠 智能家居协议

### Matter vs Zigbee

| 特性 | Matter | Zigbee |
|------|--------|--------|
| 标准化 | 统一协议 | 厂商自定义 |
| 互操作性 | ✅ 跨平台 | ❌ 厂商锁定 |
| 复杂度 | 较高 | 较低 |
| 设备生态 | 新兴 | 成熟 |
| 本地控制 | ✅ | ✅ |

### Wi-Fi vs BLE vs Zigbee

| 特性 | Wi-Fi | BLE | Zigbee |
|------|-------|-----|--------|
| 功耗 | 高 | 低 | 极低 |
| 速率 | 高 | 中 | 低 |
| 距离 | 远 | 短 | 中 |
| 设备成本 | 高 | 低 | 中 |

## 💻 ESP32 系列

| 型号 | 优势 | 适用场景 |
|------|------|----------|
| ESP32 | 成熟稳定 | 通用 |
| ESP32-S3 | AI 加速 | AIoT |
| ESP32-C3 | RISC-V 低成本 | 入门 |
| ESP32-C6 | Wi-Fi 6 + BLE | Matter |
