# 安全指南 🔐

> 整理各技术领域的安全最佳实践

---

## 🌐 网络安全

### 一般原则
- ❌ 不要在 URL 中传递敏感参数
- ✅ 使用 HTTPS 加密所有通信
- ✅ 定期更新证书
- ✅ 使用 HSTS 防止降级攻击

### Wi-Fi 安全
- ✅ 使用 WPA3/WPA2 加密
- ✅ 隐藏 SSID
- ✅ 启用客户端隔离
- ❌ 不要使用默认密码

## 🤖 AI 安全

### API 密钥
- ❌ 不要将密钥提交到 Git
- ✅ 使用环境变量存储
- ✅ 定期轮换密钥
- ✅ 使用密钥管理服务

### AI Agent 安全
- ✅ 验证所有用户输入
- ✅ 限制 Agent 权限
- ✅ 审计所有操作
- ✅ 防止提示词注入

## 📱 ESP32 安全

### 配网
- ✅ 使用安全配网（BLE Secure）
- ❌ 不要硬编码凭证
- ✅ 实现固件签名验证

### 通信
- ✅ 使用 TLS 加密
- ✅ 证书认证
- ✅ 定期更新固件

## 💾 数据安全

### 备份
- ✅ 定期自动备份
- ✅ 异地存储
- ✅ 测试恢复流程

### 加密
- ✅ 敏感数据加密存储
- ✅ 使用强加密算法（AES-256）
- ✅ 做好密钥管理

---

## 🔑 密码管理

| 原则 | 说明 |
|------|------|
| 长度 | 至少 12 位 |
| 复杂度 | 大小写 + 数字 + 特殊字符 |
| 唯一性 | 每个账户使用不同密码 |
| 管理 | 使用密码管理器 |
