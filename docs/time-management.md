# 时间管理 ⏰

> 提升效率的时间技巧

---

## Pomodoro

```bash
每 4 个番茄 → 长休息 15-30 分钟
```

## 任务优先级

### Eisenhower Matrix

| | 紧急 | 不紧急 |
|---|------|--------|
| **重要** | 立即做 | 计划做 |
| **不重要** | 委托做 | 删除做 |

## 技巧

- 每天早上先做最难的事
- 批量处理类似任务
- 学会说"不"
- 留出缓冲时间
