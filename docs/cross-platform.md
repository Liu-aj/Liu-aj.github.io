# 跨平台开发 📱

> 一套代码多端运行

---

## 框架

| 框架 | 语言 | 特点 |
|------|------|------|
| React Native | JavaScript | 成熟生态 |
| Flutter | Dart | 高性能 |
| Electron | JavaScript | 桌面应用 |
| Tauri | Rust | 轻量 |

## Flutter 示例

```dart
class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('Hello')),
        body: Center(child: Text('World')),
      ),
    );
  }
}
```
