> 整理监控与运维最佳实践

***

## 监控指标

### 系统监控
| 指标 | 说明 | 告警阈值 |
|------|------|----------|
| CPU | 使用率 | > 80% |
| 内存 | 使用率 | > 85% |
| 磁盘 | 使用率 | > 90% |
| 网络 | 流量/延迟 | 异常 |

### 应用监控
- 请求延迟
- 错误率
- QPS/TPS
- 可用性

### IoT 监控
- 设备在线率
- 数据上报延迟
- 固件版本分布

## 日志管理

### 集中式日志
- ELK Stack (Elasticsearch + Logstash + Kibana)
- Loki + Grafana
- 阿里云日志服务

### 日志级别
| 级别 | 用途 |
|------|------|
| DEBUG | 开发调试 |
| INFO | 一般信息 |
| WARN | 警告信息 |
| ERROR | 错误 |
| FATAL | 致命错误 |

## 告警策略

### 告警原则
- ✅ 告警要可操作
- ✅ 避免告警风暴
- ✅ 做好告警收敛
- ✅ 定期Review告警

### 通知渠道
- 邮件（低优先级）
- 短信（高优先级）
- 钉钉/飞书（实时）
- 电话（紧急）
