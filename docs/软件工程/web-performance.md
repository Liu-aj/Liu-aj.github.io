# Web 性能优化 ⚡

> 提升页面加载速度

***

## 指标

| 指标 | 目标 |
|------|------|
| FCP | < 1.8s |
| LCP | < 2.5s |
| FID | < 100ms |
| CLS | < 0.1 |

## 优化方法

### 资源优化
- 压缩图片 (WebP)
- 代码分割
- 压缩 CSS/JS

### 加载优化
- 懒加载
- 预加载关键资源
- CDN 分发
