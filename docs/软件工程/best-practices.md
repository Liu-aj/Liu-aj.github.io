# 最佳实践 📝

> 整理各技术领域的最佳实践

***

## 🔐 安全

### API 密钥管理
- ❌ 不要将密钥提交到 Git
- ✅ 使用环境变量或密钥管理服务
- ✅ 定期轮换密钥

### 密码存储
- ❌ 不要明文存储密码
- ✅ 使用 bcrypt/Argon2 哈希
- ✅ 添加盐值防止彩虹表攻击

## 📦 Docker

### 镜像优化
- 使用多阶段构建减小镜像体积
- 使用 `.dockerignore` 排除不必要文件
- 合并 RUN 指令减少层数

### 安全
- ❌ 不要以 root 用户运行容器
- ✅ 定期更新基础镜像
- ✅ 扫描镜像漏洞

## 🌐 Wi-Fi 配置

### ESP32 Wi-Fi
- ✅ 使用 Wi-Fi Provisioning 安全配网
- ❌ 不要硬编码 Wi-Fi 凭证
- ✅ 处理断开重连

## 🤖 AI Agent

### 成本控制
- 设置 Token 预算上限
- 使用缓存减少重复请求
- 选择合适的模型尺寸

### 可靠性
- 实现重试机制
- 添加超时处理
- 记录错误日志
