# 快捷键 ⌨️

> 常用快捷键速查

---

## 全局

| 快捷键 | 功能 |
|--------|------|
| `/` | 打开搜索框 |
| `Ctrl + K` | 打开搜索框（部分浏览器）|
| `Esc` | 关闭弹窗/取消 |

## 导航

| 快捷键 | 功能 |
|--------|------|
| `↑` | 向上滚动 |
| `↓` | 向下滚动 |
| `←` | 上一页 |
| `→` | 下一页 |
| `Home` | 返回页面顶部 |
| `End` | 跳到页面底部 |
| `T` | 返回顶部 |

## 搜索

| 快捷键 | 功能 |
|--------|------|
| `/` | 聚焦搜索框 |
| `↑` `↓` | 选择搜索结果 |
| `Enter` | 打开选中结果 |
| `Esc` | 关闭搜索 |

## 代码块

| 快捷键 | 功能 |
|--------|------|
| `📋` 按钮 | 复制代码 |
| `Ctrl + C` | 复制选中代码 |

## 主题

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + D` | 切换深色/浅色模式（部分主题）|

---

## 开发工具快捷键

### VS Code / Cursor

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + P` | 快速打开文件 |
| `Ctrl + Shift + P` | 命令面板 |
| `Ctrl + B` | 切换侧边栏 |
| `Ctrl + \` | 分屏 |
| `Ctrl + D` | 选中下一个匹配 |
| `Alt + ↑/↓` | 移动代码行 |

### Terminal

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 终止当前命令 |
| `Ctrl + Z` | 挂起当前命令 |
| `Ctrl + L` | 清屏 |
| `Ctrl + R` | 搜索命令历史 |
| `Tab` | 自动补全 |
| `Ctrl + A/E` | 行首/行尾 |
