## 🎯 快速开始

### 1. 搜索内容
按 `/` 键打开搜索框，输入关键词查找文档

### 2. 浏览分类
左侧导航栏按技术分类组织，点击分类查看该分类下所有文档

### 3. 查看最近更新
访问 [最近更新](updates.md) 页面查看最新文档

## 🔍 搜索技巧

| 技巧 | 说明 |
|------|------|
| `/` | 打开搜索框 |
| 关键词 | 输入多个关键词缩小范围 |
| 分类搜索 | 在分类页内查找 |

## 📱 快捷键

| 快捷键 | 功能 |
|--------|------|
| `/` | 打开搜索 |
| `←` `→` | 上一页/下一页 |
| `↑` `↓` | 上下滚动 |
| `t` | 返回顶部 |
