## 1. 原厂耗材推荐

### 1.1 Bambu PLA Basic — 综合最佳

PLA 是 A1 的默认推荐耗材，新手友好，打印成功率高。

| 参数 | 数值 |
|------|------|
| 直径 | 1.75 mm |
| 净重 | 1 kg/卷 |
| 喷嘴温度 | 190 – 230 °C |
| 热床温度（Cool Plate） | 35 – 45 °C |
| 热床温度（高温板） | 60 – 70 °C |
| 打印速度 | **< 300 mm/s** |
| 回抽长度 | 0.6 – 1.0 mm |
| 回抽速度 | 20 – 40 mm/s |
| 干燥条件 | 50 °C，8 h |
| 堵孔风险（XY） | ±0.02 mm（行业标准 ±0.05 mm）|
| 最大悬垂角 | 55° |
| 最大桥接长度 | 30 mm |
| Flow Ratio | **21**（A1 系列预置） |
| 建议喷嘴 | 0.2 / 0.4 / 0.6 / 0.8 mm |

**优点：**
- 打印成功率高，A1 自动校准开箱即用
- 支持 RFID 自动识别参数（AMS 多色管理）
- 直径公差极小，堵头风险低
- 速度可达 300mm/s，兼顾质量与效率
- 颜色极其丰富（玉石白、中国红、经典黑等经典色）

**适用场景：**
- 装饰品、摆件、模型
- 教学/新手练习
- 批量快速打印
- 不需要耐高温/高强度的日常用途

**不适用：** 户外用途、承重零件、长期 UV 暴露环境

---

### 1.2 Bambu PETG HF — 高速稳定版

PETG HF（High Flow）是 Bambu Lab 推出的**高速 PETG**，与标准 PETG定位不同。

> ⚠️ **注意：** 2026年 Bambu Lab 重新推出了 **PETG Basic**（新版），弯曲强度、层间强度、韧性均优于 PETG HF，但打印速度较慢。两者是**不同定位的产品**，并非简单的更新换代。

| 参数 | PETG HF | PETG Basic（新版 2026） |
|------|---------|----------------------|
| Flow Ratio（流率） | **21** | 低于 HF（约 <12） |
| 最大打印速度 | ~300 mm/s | 较低 |
| 层间附着力 | 中等 | **更高** |
| 弯曲强度 | 中等 | **更高** |
| 韧性（抗冲击） | 中等 | **更高** |
| 表面效果 | 柔光 soft-glow，黑色尤为突出 | 标准光泽 |
| 耐候性（户外） | 良好 | 良好 |
| 吸湿敏感度 | **极高**（暴露空气中快速受潮）| 高 |

**PETG HF 核心优势：**
- Flow Ratio 21，与 PLA 持平，可高速打印兼顾外观
- 柔光质感（soft-glow），视觉档次明显高于普通 PETG 光泽
- 比 PLA 更耐老化：PLA 约 1–1.5 年室内使用后开始脆断，PETG HF 长期稳定
- 比标准 PETG 更适合 A1 的高速喷头系统

**PETG HF 最大缺陷 — 吸湿极敏感：**
- 短时间（1–3天）暴露在空气中即可导致打印质量问题
- 轻度受潮：打印件表面发白（仅美观影响）
- 严重受潮：打印表面凹凸不平，K 值偏移，出现 Under-extrusion
- **必须使用干燥盒（Polydryer 等）保存，** 每次打印前务必干燥（建议 60–70 °C，4–6 h）

**适用场景：**
- 装饰性零件（非承重）
- 高速打印同时需要一定耐久性
- 需要优于 PLA 外观的展示件
- 室内长期摆放物件

**不适用：** 承重结构件、户外长期使用（选 ASA）、极潮湿环境

## 2. 第三方耗材评测

### 2.1 Elegoo Rapid PETG

Elegoo Rapid PETG 是目前社区口碑最好的第三方高速 PETG 之一，主打与 Bambu 高速打印系统兼容。

| 参数 | 数值 |
|------|------|
| 直径 | 1.75 mm |
| Flow Ratio | **0.95 – 0.96**（需手动在 Bambu Studio 中设置） |
| K 值（典型） | **0.030** |
| 最大体积流速 | 18 – 30 mm³/s（0.4mm 喷嘴下可达 30） |
| 标称最高速度 | 600 mm/s |
| 实际稳定速度 | ~250 mm/s（0.4mm 喷嘴，A1 实测）|

**社区实测反馈（Facebook 群组 + Bambu Forum）：**
- 在 0.4mm 标准喷嘴下，使用 Flow Ratio 0.95，K 值 0.030，可稳定达到 250mm/s 打印
- 多名用户报告"即插即用"，只需在 Bambu Studio 中加载 MakerWorld 社区共享配置即可
- 比 Bambu PETG HF**便宜约 30–40%**，性能差距不大
- 线径一致性好，stringing（拉丝）控制优秀
- 建议搭配**干燥后使用**，Elegoo 吸湿控制优于 Bambu PETG HF，但仍需干燥

** Bambu Studio 配置建议：**
```
喷嘴温度：240 – 255 °C
热床温度：70 – 80 °C
打印速度：200 – 300 mm/s
Flow Ratio：0.95（不要用默认的 1.0）
K 值：0.030（通过 PA 校准后取此值附近）
冷却：50 – 80%
```

### 选材建议速查

```
需要承重/结构件？→ PETG Basic（新版）或标准 PETG

预算有限，高速打印？→ Elegoo Rapid PETG
```

## 4. 耗材参数详解

### 4.1 Flow Ratio（流率）

**定义：** 实际挤丝量 / 理论挤丝量的比值。用于补偿熔融塑料在热端管内的压缩和膨胀效应。

| Flow Ratio | 含义 |
|-----------|------|
| **< 1.0**（如 0.95）| 实际出丝偏多 → 需减少流量（过挤出）|
| **= 1.0** | 理想状态，理论值与实际一致 |
| **> 1.0**（如 1.03）| 实际出丝偏少 → 需增加流量（欠挤出）|

- A1 系列打印机内置**流量动态校准（Flow Dynamics Calibration）**，打印前会自动用涡流传感器测量压力并计算 K 值
- 如果没有手动校准，A1 会**自动执行 PA 测试**，无需用户干预
- 第三方耗材建议在 Bambu Studio 的**耗材配置页面**手动设置 Flow Ratio（如 Elegoo Rapid PETG → 0.95）

### 4.2 K 值（Flow Dynamics / Pressure Advance）

**定义：** 压力提前补偿系数，用于在加速/减速时提前/延迟开始挤丝，抵消熔融塑料在Bowden管中的压缩延迟。

**典型 K 值参考：**

| 耗材 | K 值范围 | 备注 |
|------|---------|------|
| Bambu PLA Basic | 0.020 – 0.025 | 预置，无需调整 |
| Bambu PETG HF | 0.026 – 0.037 | 预置 |
| Elegoo Rapid PETG | **0.030** | 社区实测典型值 |
| eSUN PETG | 0.025 – 0.035 | 需校准 |
| Sunlu PETG | 0.022 – 0.032 | 较稳定 |

**校准方法（以 Bambu Studio 为例）：**
1. 装载耗材 → 进入「打印设置」→「耗材」→「流量动态校准」
2. 选择「启用流量动态校准」→ 开始打印
3. 打印机在打印准备阶段自动测量并存储 K 值
4. K 值会保存在该耗材配置文件中，后续打印自动复用

### 4.3 自动校准（A1 系列）

A1 系列配备**涡流传感器**（位于热端上方），可在每次打印前自动校准 K 值：

- **未更换耗材/喷嘴**：复用上次校准结果，跳过校准步骤
- **更换耗材或喷嘴**：重新执行动态流量校准
- **建议**：每隔一段时间（2–4 周）对常用耗材重新校准一次，以确保精度

## 5. 国产替代建议

### 5.1 闭眼入推荐（零调参）

| 品牌 + 型号 | 推荐理由 | 适合人群 |
|-----------|---------|---------|
| **Elegoo Rapid PETG** | 高速 PETG，Flow 0.95 + K 0.030 开箱即用，价格是 Bambu 的 60% | 高速打印用户，替代 PETG HF |
| **Sunlu PETG** | 社区公认"最便宜但表现好"，线径极稳定 | 预算优先，质量稳定优先 |
| **eSUN PETG+** | 改性 PLA+，韧性是普通 PLA 的 2 倍，兼容 Bambu 调参 | 需要比 PLA 更强韧但不想用 PETG |
| **Polymaker PETG HF** | 高密度测试显示接近原厂品质，有高速版 | 追求品质的高端用户 |

### 5.2 购买警告

- ❌ **闲鱼/二手散装**：无法确认保存条件（是否受潮），新手难以排查问题
- ❌ **极低价（<¥20/kg）**：多为库存老料，直径公差差，打印成功率低
- ❌ **无牌 3D 耗材**：常见问题：线径不均、气泡、杂质

### 5.3 品牌横向参考

```
价格从高到低：
Bambu 原厂 ≈ Polymaker > Elegoo Rapid PETG > eSUN > Sunlu > 无牌

品质稳定性：
Bambu 原厂 > Polymaker > Elegoo ≈ eSUN > Sunlu >> 无牌

高速场景推荐：
Elegoo Rapid PETG > Bambu PETG HF > Polymaker PETG HF

普通场景性价比：
Sunlu PETG > eSUN PETG > Elegoo Rapid PETG
```

### 6.1 渠道对比

| 渠道 | 价格 | 保障 | 适合场景 |
|------|------|------|---------|
| **Bambu 官方旗舰店** | ¥59–79/卷（原价）| 正品保障，RFID 原装，售后完善 | 追求零调参开箱即用 |
| **京东自营 / 天猫旗舰店** | 同上，常有满减/百亿补贴 | 快速发货，保真 | 急需，信任京东物流 |
| **淘宝/天猫第三方** | 约 8–9 折 | 需选信誉好的店铺 | 熟悉行情者 |

| **1688 批发 / 工厂店** | 约 6–8 折（多卷起批）| 需鉴别，批量采购首选 | 资深用户大量用卷 |
| **Taobao 拓竹认证店铺** | 接近官方价 | 正品保障 | 稳妥选择 |

### 6.2 购买策略建议

**新手 / 日常使用：**
> 官方旗舰店或京东自营购入 Bambu PLA Basic + PETG HF，各 1–2 卷。享受 RFID 自动识别，无需调参。

**性价比用户（PETG 为主）：**
> 主购 Elegoo Rapid PETG（约 ¥40–50/卷），搭配 Bambu PETG HF（少量，用于高速+外观件）。

**高频打印用户（月用量 >3 卷）：**
> 通过 1688 找工厂店批发 Sunlu 或 eSUN PETG，10 卷起批，单价可至 ¥25–35/kg。

**闲鱼购入注意事项：**
- ⚠️ 仅限有良好评价记录的老卖家
- ⚠️ 收到后务必**干燥处理**（60 °C，4–6 h）再上机
- ⚠️ 先小量试印，确认无问题再大量购入
- ⚠️ 注意是否为正品（检查线径一致性、标签、防潮包装）
