## 项目一：E-ink 天气显示屏 — 低功耗桌面常显

### 🎯 核心原理

利用 ESP32 的 WiFi 能力从天气 API（心知天气 / OpenWeatherMap）定时拉取预报数据，通过 SPI 总线驱动电子纸屏幕显示。电子纸（E-ink）只在刷新时耗电，断电后画面依然保持，极其适合桌面长期常驻。ESP32 进入 Deep Sleep 模式，每次唤醒后刷新一次（间隔 15~60 分钟），整体功耗可低于 50μA。

|------|------|------|-------------|
| 主控 | ESP32 DevKit-C / Lolin32 | 1 | 25–35 |
| 电子纸屏 | WaveShare 2.9" B / 4.2" 三色 | 1 | 80–150 |
| 布线和连接器 | dupont 线 / 排针 | 若干 | 5 |
| 外壳（可选） | 3D 打印或激光切割 | 1 | 自定 |
| **合计** | | | **约 ¥110–190** |

> 💡 推荐 2.9" B（红黑白三色）性价比最高；如需更大可视面积选 4.2"

### 🔑 关键代码框架（Arduino / MicroPython）

**Arduino 版本（推荐）**

```cpp
#include <FastLED.h>
#include <AceButton.h>
#include <SSD1306.h>
#include <Servo.h>

#define LED_PIN     7
#define NUM_LEDS    8
#define TOUCH_PIN   2
#define SERVO_PIN   6

CRGB leds[NUM_LEDS];
SSD1306  display(0x3c, 4, 5);  // SDA=4, SCL=5
Servo myServo;

// 宠物状态枚举
enum PetState { IDLE, HAPPY, ANGRY, SLEEPY, DEMANDING };
PetState state = IDLE;
unsigned long lastInteraction = 0;

void setup() {
    FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
    display.init();
    myServo.attach(SERVO_PIN);
    // 初始化触摸引脚
    pinMode(TOUCH_PIN, INPUT);
    xTaskCreatePinnedToCore(ledTask, "LED", 4096, NULL, 1, NULL, 0);
    xTaskCreatePinnedToCore(servoTask, "SERVO", 2048, NULL, 1, NULL, 1);
}

void loop() {
    if (digitalRead(TOUCH_PIN) == HIGH) {
        state = HAPPY;
        lastInteraction = millis();
    }
    // 超过 30 秒无互动 → 进入求关注状态
    if (state == IDLE && millis() - lastInteraction > 30000) {
        state = DEMANDING;
    }
    drawFace(state);
    delay(50);
}

// LED 动画任务（Core 0）
void ledTask(void* param) {
    while (true) {
        if (state == HAPPY) {
            fill_rainbow(leds, NUM_LEDS, (millis() / 20) % 255);
        } else if (state == SLEEPY) {
            fadeToBlackBy(leds, NUM_LEDS, 2);
        } else {
            fill_solid(leds, NUM_LEDS, CRGB::Blue);
        }
        FastLED.show();
        vTaskDelay(50 / portTICK_PERIOD_MS);
    }
}
```

## 项目三：吉他练习辅助器 — 调音器 + 节拍器

### 🎯 核心原理

**调音器**：通过 I2S 麦克风（INMP441）采集音频，使用自相关（Autocorrelation）或 YIN 算法检测基频，与标准音高（E2=82.41Hz, A2=110Hz, D3=146.83Hz, G3=196Hz, B3=246.94Hz, E4=329.63Hz）比对，计算音分（Cents）偏差并显示。

**节拍器**：使用 ESP32 定时器精确输出 BPM 可调的脉冲信号，驱动蜂鸣器或舵机产生有节奏的"嘀嗒"声，支持 Tap Tempo（敲击测速）。

### 📦 硬件 BOM

| 物料 | 型号 | 数量 | 参考价（¥） |
|------|------|------|-------------|
| 主控 | ESP32 DevKit | 1 | 25–35 |
| 麦克风 | INMP441 I2S 数字麦克风 | 1 | 15–25 |
| 显示 | 0.96" OLED 或 1.3" IPS LCD | 1 | 12–20 |
| 音频输出 | 无源蜂鸣器 / 有源音箱 | 1 | 5–10 |
| 按键 | 轻触按键 × 4 | 4 | 3–6 |
| 电源 | 3.7V 锂电 + TP4056 充电 | 1 | 10–15 |
| 外壳 | 3D 打印 | 1 | 自定 |
| **合计** | | | **约 ¥70–115** |

### 🔑 关键代码框架（调音器核心算法）

```cpp
#include <driver/i2s.h>
#include <ArduinoFFT.h>

static const i2s_port_t I2S_PORT = I2S_NUM_0;
static const int SAMPLE_RATE = 44100;
static const int SAMPLES = 4096;

float detectPitch(float* samples, int count) {
    // 自相关算法 — 找峰值对应周期
    float maxCorr = 0;
    int bestLag = 0;
    for (int lag = 50; lag < 800; lag++) {  // 约 55Hz ~ 880Hz 范围
        float corr = 0;
        for (int i = 0; i < count - lag; i++) {
            corr += samples[i] * samples[i + lag];
        }
        if (corr > maxCorr) {
            maxCorr = corr;
            bestLag = lag;
        }
    }
    return (float)SAMPLE_RATE / bestLag;  // 基频 Hz
}

void setup() {
    // I2S 麦克风配置（INMP441）
    i2s_config_t i2s_config = {
        .mode = (i2s_mode_t)(I2S_MODE_MASTER | I2S_MODE_RX),
        .sample_rate = SAMPLE_RATE,
        .bits_per_sample = I2S_BITS_PER_SAMPLE_32BIT,
        .channel_format = I2S_CHANNEL_FMT_ONLY_LEFT,
        .communication_format = I2S_COMM_FORMAT_I2S,
        .intr_alloc_flags = ESP_INTR_FLAG_LEVEL1,
        .dma_buf_count = 8,
        .dma_buf_len = 256,
    };
    i2s_pin_config_t pin_config = {
        .bck_io_num = 26, .ws_io_num = 22, .data_out_num = I2C_PIN_NO_CHANGE, .data_in_num = 32
    };
    i2s_driver_install(I2S_PORT, &i2s_config, 0, NULL);
    i2s_set_pin(I2S_PORT, &pin_config);
}

void loop() {
    float samples[SAMPLES];
    size_t bytes_read;
    i2s_read(I2S_PORT, samples, sizeof(samples), &bytes_read, portMAX_DELAY);
    int sampleCount = bytes_read / sizeof(float);

    float freq = detectPitch(samples, sampleCount);
    int cents = 1200 * log2f(freq / targetFreq); // 计算音分偏差

    // OLED 显示音名 + 指针偏移
    display.clear();
    display.setCursor(0, 0);
    display.printf("Freq: %.1f Hz", freq);
    display.drawHorizontalBar(32, 20, 64, map(cents, -50, 50, 0, 64));
    display.display();
}
```

### ⭐ 难度评级：★★★★☆（4/5）

## 项目四：16×16 WS2812B LED 音频可视化 — FFT 频谱

### 🎯 核心原理

通过 I2S 麦克风采集环境声音，使用 ArduinoFFT 库在 ESP32 双核上分别执行采样和 FFT 运算，将音频频谱映射到 16×16 LED 矩阵的列向高度，每列代表一个频段的能量值。结合 FastLED 库实现流畅的彩虹/瀑布动画，帧率可达 30+ FPS。

### 📦 硬件 BOM

| 物料 | 型号 | 数量 | 参考价（¥） |
|------|------|------|-------------|
| 主控 | ESP32 DevKitC（双核） | 1 | 25–35 |
| LED 矩阵 | WS2812B 16×16（256 灯）5050 RGB | 1 | 35–60 |
| 麦克风 | INMP441 或 SPH0645 I2S 数字硅麦 | 1 | 15–25 |
| 电源 | 5V 4A DC 电源适配器（WS2812B 峰值电流大） | 1 | 20–30 |
| 电容 | 1000μF 25V 电解电容（电源滤波） | 1 | 3–5 |
| 外壳 | 3D 打印或亚克力框架 | 1 | 自定 |
| **合计** | | | **约 ¥100–155** |

> ⚠️ **重要**：WS2812B 每灯最大电流 ~60mA（白色全亮），256 灯峰值可达 15A，务必使用 **5V 4A 以上**独立供电，切勿仅靠 USB 供电。

### 🔑 关键代码框架（Arduino + FastLED + ArduinoFFT）

```cpp
#include <FastLED.h>
#include <arduinoFFT.h>
#include <driver/i2s.h>

#define LED_PIN     15
#define MATRIX_W    16
#define MATRIX_H    16
#define SAMPLES     256           // FFT 样本数
#define SAMPLING_F  40000         // 采样率 40kHz（覆盖 20kHz 音频）

static const i2s_port_t I2S_PORT = I2S_NUM_0;
CRGB matrix[MATRIX_W * MATRIX_H];
double vReal[SAMPLES];
double vImag[SAMPLES];
arduinoFFT FFT = arduinoFFT();

TaskHandle_t fftTaskHandle = NULL;

void setup() {
    FastLED.addLeds<WS2812B, LED_PIN, GRB>(matrix, MATRIX_W * MATRIX_H);
    FastLED.setBrightness(80);
    initI2S();

    // 核 1：FFT 运算
    xTaskCreatePinnedToCore(
        fftTask, "FFT", 8192, NULL, 2, &fftTaskHandle, 1);
}

void loop() {
    // 核 0：显示更新（始终可用最新 FFT 结果）
    displaySpectrum();
    FastLED.show();
    delay(16);  // ~60 FPS 上限
}

void fftTask(void* param) {
    while (true) {
        size_t bytes_read;
        int32_t i2sData[SAMPLES];
        i2s_read(I2S_PORT, &i2sData, sizeof(i2sData), &bytes_read, portMAX_DELAY);

        for (int i = 0; i < SAMPLES; i++) {
            vReal[i] = (double)i2sData[i] / INT32_MAX;
            vImag[i] = 0;
        }
        FFT.Windowing(vReal, SAMPLES, FFT_WIN_TYP_HAMMING, FFT_FORWARD);
        FFT.Compute(vReal, vImag, SAMPLES, FFT_FORWARD);
        FFT.ComplexToMagnitude(vReal, vImag, SAMPLES);

        vTaskDelay(1 / portTICK_PERIOD_MS);
    }
}

void displaySpectrum() {
    memset(matrix, 0, sizeof(matrix));
    // 映射 128 个 FFT bin 到 16 列，每列取对数平均
    for (int col = 0; col < MATRIX_W; col++) {
        int binStart = pow(2, col * 10.0 / MATRIX_W);
        int binEnd   = pow(2, (col + 1) * 10.0 / MATRIX_W);
        float avg = 0;
        for (int b = binStart; b < binEnd && b < SAMPLES / 2; b++) {
            avg += vReal[b];
        }
        avg /= (binEnd - binStart);
        int height = map((int)avg, 0, 200, 0, MATRIX_H);  // 映射到列高
        height = constrain(height, 0, MATRIX_H);

        // 彩虹色：色相随频率变化
        for (int row = 0; row < height; row++) {
            matrix[XY(col, MATRIX_H - 1 - row)] =
                CHSV(map(col, 0, MATRIX_W, 0, 255), 255, 200);
        }
    }
}

// LED 矩阵坐标映射（蛇形）
int XY(int x, int y) {
    if (y % 2 == 0) return y * MATRIX_W + x;
    else return y * MATRIX_W + (MATRIX_W - 1 - x);
}
```

```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include "camera.h"

const char* WIFI_SSID = "your_wifi";
const char* WIFI_PASS = "your_password";
const char* GAS_URL = "https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec";

static camera_config_t getCameraConfig() {
    camera_config_t cfg = {
        .pin_pwdn  = -1,
        .pin_reset = 15,
        .pin_xclk  = 27,
        .pin_sscb_sda = 25,
        .pin_sscb_scl = 23,
        .pin_d7 = 19, .pin_d6 = 36, .pin_d5 = 18, .pin_d4 = 21,
        .pin_d3 = 39, .pin_d2 = 35, .pin_d1 = 13, .pin_d0 = 4,
        .pin_vsync = 5, .pin_href = 21, .pin_pclk = 22, .pin_fref = 26,
        .xclk_freq_hz = 20000000,
        .ledc_timer = LEDC_TIMER_0,
        .pixel_format = PIXFORMAT_JPEG,
        .frame_size = FRAMESIZE_SVGA,   // 800×600
        .jpeg_quality = 10,
        .fb_count = 2,
    };
    return cfg;
}

void setup() {
    Serial.begin(115200);
    WiFi.begin(WIFI_SSID, WIFI_PASS);

    camera_config_t config = getCameraConfig();
    esp_camera_init(&config);
}

void loop() {
    camera_fb_t* fb = esp_camera_fb_get();
    if (!fb) return;

    // 上传到 Google Drive
    HTTPClient http;
    http.begin(GAS_URL);
    http.addHeader("Content-Type", "multipart/form-data");

    static char formData[256];
    snprintf(formData, sizeof(formData),
             "fileName=capture_%lu.jpg", millis());

    int code = http.sendRequest("POST", fb->buf, fb->len);
    Serial.printf("Upload code: %d\n", code);
    http.end();

    esp_camera_fb_return(fb);
    delay(60000);  // 每分钟拍一张
}
```

## 项目六：WiFi / 蓝牙 / ESP-NOW 多协议遥控器

### 🎯 核心原理

用 ESP32 同时实现三种无线协议，通过物理按键或摇杆发送控制指令：

| 协议 | 频段 | 延迟 | 特点 |
|------|------|------|------|
| **WiFi** | 2.4GHz | ~50ms | 距离远（百米级），可互联网远程 |
| **蓝牙 Classic** | 2.4GHz | ~30ms | 手机直连，功耗适中 |
| **ESP-NOW** | 2.4GHz | **< 10ms** | Espressif 专属协议，无需路由器，点对点极低延迟 |

三种协议共享同一硬件，按键事件通过协议适配层分发，接收端 ESP32 根据协议类型响应电机或舵机。

### 🔑 关键代码框架（多协议发送端，Arduino）

```cpp
#include <WiFi.h>
#include <BluetoothSerial.h>
#include <esp_now.h>

BluetoothSerial SerialBT;
uint8_t receiverMac[] = {0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX};

// Joystick XY
#define JOY_X  34
#define JOY_Y  35
#define BTN_A  32

// --- ESP-NOW 初始化 ---
void initESPNOW() {
    if (esp_now_init() != ESP_OK) {
        Serial.println("ESP-NOW init failed");
        return;
    }
    esp_now_peer_info_t peer = {};
    memcpy(peer.peer_addr, receiverMac, 6);
    peer.channel = 0;
    peer.encrypt = false;
    esp_now_add_peer(&peer);
}

// --- 数据包格式 ---
struct Packet {
    uint8_t protocol;  // 0=ESPNOW, 1=WIFI, 2=BT
    int16_t joyX;
    int16_t joyY;
    bool btnA;
};
Packet pkt;

void setup() {
    Serial.begin(115200);

    // WiFi 初始化（UDP）
    WiFi.mode(WIFI_MODE_STA);
    WiFi.begin("遥控器AP", "password");  // 或连接到同一路由器

    // 蓝牙初始化
    SerialBT.begin("ESP32_Remote");

    // ESP-NOW
    initESPNOW();
}

void loop() {
    pkt.joyX = analogRead(JOY_X) - 2048;  // 归中
    pkt.joyY = analogRead(JOY_Y) - 2048;
    pkt.btnA = !digitalRead(BTN_A);       // 按下为 true

    // === 协议选择（可按键切换）===
    static uint8_t activeProtocol = 0;    // 0=ESPNOW, 1=WIFI, 2=BT

    if (activeProtocol == 0) {
        // ESP-NOW（最低延迟）
        pkt.protocol = 0;
        esp_now_send(receiverMac, (uint8_t*)&pkt, sizeof(pkt));
    } else if (activeProtocol == 1) {
        // WiFi UDP
        pkt.protocol = 1;
        WiFiUDP udp;
        udp.beginPacket("192.168.1.100", 8888);
        udp.write((uint8_t*)&pkt, sizeof(pkt));
        udp.endPacket();
    } else {
        // 蓝牙
        pkt.protocol = 2;
        SerialBT.write((uint8_t*)&pkt, sizeof(pkt));
    }

    // 协议切换检测（长按某键）
    delay(50);
}
```
